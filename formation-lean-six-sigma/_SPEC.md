# Spécification d'auteur — Modules de la formation

> Document interne. Sert de **référence unique** pour rédiger chaque module de façon
> homogène. Tout module du parcours doit respecter cette structure et ces règles.

## Principes directeurs

1. **Langue : français.** Le contenu source est en français (Progress Partners — « La
   passion de la performance »). On conserve la langue et la terminologie d'origine.
2. **Exhaustivité.** *Tout* le contenu pédagogique des fichiers source doit être repris :
   chaque concept, définition, liste, tableau, formule, exemple, chiffre. On **réorganise**
   pour la lisibilité, on ne **résume** pas au point de perdre de l'information.
3. **Orientation « action ».** Objectif du parcours : *être capable d'appliquer le contenu
   directement après chaque module*. Chaque module se termine donc par une section
   **« Application directe »** avec un exercice concret, transposable au terrain du stagiaire.
4. **Autoportant.** Le module se lit seul. Les schémas/visuels non transcriptibles sont
   décrits puis renvoyés au fichier source Drive.
5. **Attribution.** Mentionner la source Progress Partners en pied de module.

## Lien vers un fichier source Drive

Construire le lien ainsi : `https://drive.google.com/file/d/<ID_DU_FICHIER>/view`

## Règles de rédaction

- Tableaux Markdown pour toute donnée tabulaire (niveaux sigma, grilles, comparatifs…).
- Conserver les chiffres exacts des sources (ex. niveaux sigma → DPMO, %).
- Reprendre les formules (ex. Loi de Little) en clair.
- Mettre en gras les **définitions** et les **mots-clés** à la première occurrence.
- Les exercices d'« Application directe » doivent être **réalisables sans le formateur**.
- Viser un module riche : ne pas tronquer le contenu source pour « faire court ».
